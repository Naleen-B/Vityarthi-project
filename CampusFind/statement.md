# Project Statement

## Project Title
CampusFind — Smart Lost & Found Matching System

## Problem Statement

In a college environment, lost belongings are often reported through informal messages or notices. A person who finds an item may not know who lost it, while the owner may not know that someone has found it. Searching manually through reports is time-consuming.

CampusFind provides a centralized Python-based system where lost and found items can be recorded and searched. The system additionally compares related fields and text descriptions to suggest possible matches.

## Scope

The project covers:
- Lost-item registration
- Found-item registration
- Search and filtering
- Rule-based matching
- Match scoring
- Basic statistics
- Local JSON storage

The project does not cover real-world identity verification, payment, messaging, or production deployment.

## Target Users

- College students
- Faculty members
- Campus staff
- Campus lost-and-found coordinators

## High-Level Features

1. Lost item registration
2. Found item registration
3. Search
4. Smart matching
5. Match explanation
6. Statistics
7. Persistent JSON storage
